# Planetary defense

PLNATK, DECWAR.FOR:2800–2858, iterates planet order and rolls once for each
neutral planet before any target search. Player-triggered cycles skip friendly
planets. Player attacks use integer(50+30*construction)/NUMPLY; the Romulan
branch passes undivided50+30*construction. Both ranges are2. Owned-planet
awards update TMSCOR directly; neutrals skip scoring. Recipient union is
distance10 PTEAM plus distance4 both, so a neutral planet selects both factions
at10 and an owned planet extends only its own faction's audience. This differs
from BASPHA's triggering-TEAM audience. The focused helper tests power and
activation selection, not a complete mutable multi-target defense cycle.
